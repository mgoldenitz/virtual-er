# Known issues and gotchas

- Norton re-signs HTTPS. Node in the owner's own terminal fails server-side Supabase calls without --use-system-ca; `npm run dev` adds it (scripts/dev.mjs). Claude's Bash shell already trusts the certificate, which hides the problem.
- Python here: `python -I` ignores PYTHONIOENCODING. Use `python -I -X utf8` for Urdu, Arabic, Chinese or symbols. Long heredoc scripts get mangled; write the script to a file first. Put code text that holds a backslash (a regex such as \bmin\b) in a raw string (r'''...'''), or Python changes \b into a backspace.
- Do not edit text that has backslashes (regex, escapes) with `sed` or `printf` in the Bash tool; the shell removes or changes them (`printf` turns `\201` into one byte). Use Edit, or a quoted heredoc (`cat > file <<'EOF'`) for a temporary file.
- Claude Code keeps per-project settings (switched-off MCP servers) under the folder path in ~/.claude.json. Moving the project folder loses them.
- The Supabase MCP is read-only and often fails to connect. The owner runs database changes in the SQL Editor.
- Playwright cannot sign in as staff; the owner does the staff half of browser tests.
- Playwright MCP: `target` takes a ref from the last snapshot (for example `e73`), a CSS selector or a locator, never the role text from the snapshot (`combobox "Select language"` fails). Load the tool schema with ToolSearch before the first call.
- The Vercel MCP cannot change firewall settings or list cron jobs; the owner does these in the dashboard.
- Hook scripts: text piped from PowerShell starts with an invisible byte-order mark, so JSON.parse fails and the script exits silently. Strip `\uFEFF` first. In Git Bash, Node does not read paths like /c/Users; test with C:/Users paths.
- navigator.onLine says "online" on Wi-Fi with no internet or behind a hotel or hospital sign-in page (captive portal), so the offline banner does not show there. Accepted for the demo (Gemini review 2026-11-14): the app does not test a real connection. It asks again when the page comes back on screen (`data/useOnline.ts`).
- Open: Vercel firewall rate-limit rule for GET /api/site-status (owner).
- Not done: when another staff screen pauses or resumes a site, the pause banner appears but is not announced to screen readers on this screen (Gemini pause review, point 4b, 2026-11-14).
- TaskStop does not always end a Next dev server that Claude started; the node process can stay on port 3000. Check with `netstat -ano | findstr :3000` and ask the owner before stopping it.
- Some files have CRLF line ends, and multi-line Edit calls can miss on them. Use a small Python edit script in the job's tmp folder that keeps the line ends.
- `formatMinutes` has no day unit: 25 hours shows "25h". Accepted, because no demo visit stays open for a day (Gemini review c2, 2026-11-15).
- happy-dom's `click()` does not move focus to the button. Click tests call `target.focus()` first, as a mouse click or the Enter key does, or focus checks pass or fail for the wrong reason. To test a phone tap (focus stays on the page body), click without `focus()`.
- React puts two state updates from one event into one commit. When the state ends with no change, a `[state]` effect does not run, so a value kept in a ref for that effect can stay and decide a later change. Clear such a ref in the part that sets the next state (as `turnOn` and `turnOff` clear `backgroundFocus`).
- A test that passes before a fix is not proof. Check each new test with a small temporary code change that must make it fail, then put the code back from a copy in the job's tmp folder (not `git checkout`). For a test that searches files for banned text, make one probe for each form of that text (the character, its HTML name and number, its JS and CSS escape codes) and for each file type the test must read. When a review says "no test fails if line X is removed", first find the steps in the app that reach line X. If no steps reach it, report it as a guard, not as a missing test, before the owner chooses.
- One "Recall all" is one UPDATE, so the trigger gives every recalled visit the same `called_at` (`now()` is the transaction start). Any count of call-backs must use `distinct called_at`, or one Recall all counts as many call-backs with gaps of 0. A SQL check that needs call-backs at different times must pause the trigger inside `begin ... rollback` (`supabase/checks/wait_gap.sql`).
- The Supabase SQL Editor shows only the result of the last statement. A check file that reads results at two points (before and after more inserts) must keep the first results in a temp table and show all rows in one last select, and the owner must run the whole file at once (`supabase/checks/wait_gap.sql`).
- In Git Bash, `tail -3` with more than one file fails ('option used in invalid context'); use `tail -n 3`. Never put a check command in the same `&&` chain as an append (`cat >>`): if the check fails, the append has already run, and a second try appends again. Run the append alone, then check.
- After the 24-hour clean-up deletes a visit, the patient's phone shows "This link did not work" and forgets the token. The visit is over by then, so this stays (2026-11-16).
- Through the read-only Supabase MCP, `information_schema.role_table_grants` gives no rows for `anon` and `authenticated`, because it shows only roles that the current user belongs to (`supabase_read_only_user`). So `supabase/checks/permissions.sql` now uses `has_table_privilege(role, table, right)`, which works for any role; do not go back to `role_table_grants` in a check that Claude runs (2026-11-16).
- A message that tells staff what the screen will show next must also be true when the network is down at that moment. A save can fail with "could not be reached" in place of the reason the message names (found 2026-11-17, check-in stale read warning).
- A message that comes on its own (from a background read, not from a press) goes in a `role="status"` element that is always on the page, below the controls it is about, so screen readers hear it and the buttons do not move (`components/staff/CheckInPanel.tsx`, `stale-read-warning`).
- A test for a button label with `toContain("Waits on-site")` also passes on a longer label that starts with those words. To check the exact label, match the whole tag: `toMatch(/<button[^>]*>Waits on-site<\/button>/)` (found 2026-11-17).
- In a Python script, `\\"` in a normal string writes a backslash before the quote into the file. For text that has quotes, use Edit, or check the file for `\\"` after the script runs (found 2026-11-17, `docs/decisions.md` line 61).
- The Write and Edit tools turn a `\u` escape code for a curly quote or another symbol into the real character. In a file that must not hold the character (for example `lib/straightQuotes.test.ts`), build it with `String.fromCharCode(0x2019)`, and Grep the file after the edit (found 2026-11-17).
- Sideways overflow checks: `scrollWidth` does not show overflow off the left side of a right-to-left page (Urdu, Arabic). Check each part's `getBoundingClientRect()` for `left < 0` or `right > clientWidth`, as the `.playwright-mcp` axe helpers do (found 2026-11-17).
- Playwright MCP `browser_run_code_unsafe` with `filename` loads files only from the allowed folders; keep helper scripts in `.playwright-mcp/` (git does not track it). ESLint reads that folder, so each helper there gives one `no-unused-expressions` warning; GitHub does not have the files (found 2026-11-17).
- Tailwind 4 makes CSS only for class names it finds in the source files. A class added only in the browser (DevTools or Playwright) does nothing, so test a layout idea there with direct styles (`el.style.gridTemplateColumns`), then put the class in the code (found 2026-11-17).
- Things that do not get smaller than their content: a grid with no column rule (its `auto` column grows to fit its widest part; use `grid-cols-1`, which is `minmax(0, 1fr)`), a `select` (as wide as its longest choice; add `max-w-full`), a `fieldset` (browser default `min-width: min-content`; add `min-w-0`), and a flex row with no `flex-wrap` (found 2026-11-17, `/staff` at 200% text).
- Browsers block `navigator.vibrate` before the first tap on the page and write a console error, even for `vibrate(0)`. `stopVibration()` in `components/patient/alertSound.ts` calls the phone only after a vibration started (found 2026-11-17).
- `navigator.vibrate()` gives back false and no error when the browser blocks it. Read the result before you mark a vibration as started (`components/patient/alertSound.ts`, Gemini review 2026-11-17, point 4.1). A test mock for it must give back a boolean too.
